# Working state

**Decision state:** draft the bounded research note **One Canonical Identity,
Different Policy Outcomes: A Bounded Measurement of JSON Receipt Semantics.**
The frozen evidence supports no definitive or top-tier thesis.

**What remains publishable:** a reproducible, decision-conditioned measurement:
a selected Ghost-Ark receipt identity is tested against version-pinned,
third-party policy/validation engines using author-supplied equality policies.
This is an operational measurement result, not novel consumer-relative
canonicalization theory.

**Evidence spine:** E1, E1-B, E7, E11, E16, and E12. E13 is a
configuration-bounded placement argument; E14 and receipt-verifier work are
artifact context, not headline evidence.

**Central adverse result:** E12 observed 0 selected pathology instances in 64
eligible stored intoto payloads from 16 producers. The note calls this a
bounded ecological null and does not turn it into a traffic or producer
prevalence statement.

**Consequence boundary:** E16 reports eight decision-split cells across four
engines, but those are author-supplied policy-engine outcomes, not outcomes at
real receipt relying parties. The checked-in report records host:
"unrecorded-host"; do not attach host-specific language.

**Highest-leverage next experiment:** preregister a case study in an externally
maintained signed structured-data ecosystem with independently authored,
versioned decision paths and a second population. It must include a strict
baseline, controls, a population/producer analysis, and a way for the result to
be null. A TUF-related ecosystem is promising only after its actual
canonicalization/reparse boundary is established; DSSE is a corpus source here,
not the target.
